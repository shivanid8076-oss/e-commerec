1. PROJECT OVERVIEW & ARCHITECTURE
---------------------------------------------------------------------
Name: Vastram (Formerly Rishigyan)
Type: Secure, Enterprise-Grade E-Commerce Store & Seller Dashboard
Architecture: 
- Frontend: React.js (Vite)
- Backend: Node.js with Express.js
- Database ORM: Prisma
- Data Visualization: Recharts

2. UI/UX DESIGN & AESTHETICS (FRONTEND)
---------------------------------------------------------------------
The entire store, specifically the Seller Dashboard, has been upgraded to a "Pro-Level" modern aesthetic, taking inspiration from top-tier platforms like Stripe and Apple:
- Glassmorphism: Cards, tooltips, and sidebars feature blurred transparent backgrounds that adapt to the underlying canvas.
- Dynamic Theming: A 1-click seamless toggle between "☀️ Light Mode" (Crisp White/Silver glass) and "🌙 Dark Mode" (Deep Slate & Rose Pink accent) without page reloads.
- Minimalist Typography: Clean, non-cluttered fonts with generous spacing.
- Vibrant Gradients: Subtle neon-like hover effects and trend indicator pills (e.g., +12.5% Growth) for a highly professional look.
- Interactive Feedback: Smooth CSS keyframe animations, toast notifications, and hover elevations.

4. ENTERPRISE-LEVEL SECURITY (BACKEND)
---------------------------------------------------------------------
The "Secure-App" backend features 5 robust middlewares to protect the store:
- Authentication (auth.js): JWT-based verification ensuring strict Role-Based Access Control (RBAC). Only Admins can access the dashboard.
- DDoS Protection (rateLimiter.js): Prevents server crashes and blocks bots from brute-forcing passwords.
- Hacker Code Blocking (sanitize.js): Neutralizes malicious scripts (XSS) and dangerous database queries before they reach the server.
- Security Logging (securityLogger.js): Maintains a permanent CCTV-like audit trail of admin logins and critical actions with IP tracking.
- Input Validation (validate.js): Ensures strict formatting for emails, passwords, and phone numbers to keep data clean.
- Password Hashing: Bcrypt encryption ensures user passwords are mathematically scrambled in the database.
- SQL Injection Proof: Handled natively by the Prisma ORM.
